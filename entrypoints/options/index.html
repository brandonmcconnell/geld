Hide test files from GitHub diffs so you can review what matters.

Enabled on GitHub

Turn Geld off to see GitHub exactly as it ships.

Hide test files

Uses the built-in patterns below. Turn off to rely on custom patterns only.

Show hidden files expanded by default

Tests still move to the bottom and are excluded from the line counts, but stay visible.

Show line counts in pull request lists

Adds +N −M (excluding tests) to each PR on list pages such as /pulls; hover for the full breakdown. Fetches each PR's diff in the background.

Custom patterns

One glob per line. Paths are matched relative to the repository root using gitignore-style rules: *.snap matches a filename anywhere, fixtures/ matches a directory anywhere, src/**/*.gen.ts matches a full path, and a leading ! rescues files the built-in patterns would hide. Matching files are treated as tests.

Built-in test patterns

These are always used while “Hide test files” is on. Grouped by kind so they can become individually switchable later.
