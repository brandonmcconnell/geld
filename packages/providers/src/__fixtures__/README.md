# Provider response fixtures

The GitLab fixture is a minimized recording of the public `gitlab-org/gitlab!1` API response, retrieved November 1, 2026.
Personal profile fields and the PR body are omitted.
The GitHub and Bitbucket fixtures are synthetic examples of their documented response contracts.
They are not represented as live recordings.
Live GitHub API and Bitbucket API recording was unavailable in the execution environment.
No authenticated response or credential is committed.
