# Dashboard workspace exploration

An alternate workspace composition with global navigation, contextual settings, a contained application surface, compact review rows, layered labels and repository filtering. Built on the existing application routes and data.

All screenshots use synthetic data. External avatars fall back to initials when their image host cannot be reached. Open preview.html for the embedded gallery.
