Repositories

Where Geld should stay off, one rule per line, like a .gitignore for repositories: acme/widgets turns Geld off in that repository, acme (or acme/*) in the whole organisation, a leading ! turns it back on, and the last matching line wins. Leave empty to run everywhere. For an allowlist, start with * and add !acme/* below it.

GitHub Enterprise Server

Geld runs on github.com out of the box. Add the hostname of your company's GitHub Enterprise Server (one per line, e.g. github.example.com) and your browser will ask you to allow Geld on that site. Geld never contacts anything other than the GitHub hosts you list here.

GitHub account

Sign in (top right) to keep these settings in sync across browsers and devices. Geld uses GitHub's device flow: you confirm a short code on github.com, and the only permission requested is gist. Your settings are stored in a secret gist on your own account named geld-settings.json. There is no Geld server and no database — nobody but you (including Geld's author) can read or change that gist, and the sign-in token never leaves this device. Signing in on another browser asks whether to keep that device's settings or use the account's. The same settings can be edited at geld.sh/settings.
